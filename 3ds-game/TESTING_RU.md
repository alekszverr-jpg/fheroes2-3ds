# Проверки 3DS: отдельные группы и время этапов

После зависания ПК 2026-10-13 автоматические запуски Azahar на этом компьютере приостановлены. Команды запуска ниже — для будущей диагностики после отдельного явного запроса пользователя. Новая инфраструктура проверена сборкой и автономными проверками, но в Azahar пока не запускалась.

## Выбор группы

`tools/test-menu-emulator.ps1` по умолчанию выбирает только `Startup` (старт/отрисовка, ввод, панель команд и прокрутка карты). `Full` требуется указать явно: он сохраняет все прежние 25 маркеров проверок компонентов и итоговый маркер завершения.

Доступны Startup, Messages, Chest, LevelUp, Recruit, Market, Gift, Hero, Army, Spellbook, BattleLog, BattleDialogs, BattleIntegration и Full. Army проверяет разделение и сведения об отряде; Spellbook — боевую, походную и полную книги; BattleDialogs — панель действий героя и результаты боя; BattleIntegration — реальные вызовы из Arena/HUD. Остальные группы соответствуют своему окну. Проверка Messages больше не вызывает другие группы внутри себя.

Безопасный просмотр плана без запуска эмулятора, подготовки данных и изменений профиля:

```powershell
./tools/test-menu-emulator.ps1 -Group Army -PlanOnly
./tools/test-menu-emulator.ps1 -Group Spellbook -PlanOnly
./tools/test-menu-emulator.ps1 -Group Full -PlanOnly
```

Будущие запуски по отдельному запросу:

```powershell
./tools/test-menu-emulator.ps1 -Group Army -Model New
./tools/test-menu-emulator.ps1 -Group Spellbook -Model New -Language en
./tools/test-menu-emulator.ps1 -Group Full -Model Old
```

Не выполнять одновременно: используется один изолированный профиль. Таймаут по умолчанию — 90 секунд для обычных групп, 120 для Spellbook/BattleDialogs/BattleIntegration, 360 для Full. Это предел ожидания, а не обещанная длительность. Старый `menu-smoke.enabled` без `menu-smoke-group.txt` оставляет прежнее полное поведение приложения; runner всегда записывает выбранную группу. Не оставлять эти файлы на SD консоли.

## Время и результаты

Группа записывает `3DS TEST BEGIN group=...` и `3DS TEST END group=... elapsed_ms=...`. Ошибка внутри группы оставляет BEGIN без END. Приложение завершает тестовый запуск после выбранной группы.

Runner сохраняет `timings.json`: подготовка ресурсов, запуск/эмуляция, проверка снимков и время завершённых групп. Этот файл обновляется во время ожидания эмулятора, поэтому принудительная перезагрузка оставляет статус incomplete и последний замер. Статус passed выставляется только после проверки всех маркеров, времени выбранных групп и требуемых снимков. При обычной ошибке лог сохраняется и профиль восстанавливается. Резервная копия `build/menu-tests/profile-recovery.json` позволяет следующему явно запрошенному запуску восстановить профиль после принудительной перезагрузки.

Отдельные группы пишут в `build/menu-tests/<модель-язык>/<группа>/`, Full сохраняет прежний каталог модели. Проверяются и копируются только снимки выбранной группы; старые соответствующие снимки удаляются из тестовой SD перед запуском, чтобы не выдать старый файл за новый результат. Azahar работает с BelowNormal и завершается до проверки изображений.

## Подготовка ресурсов

Неизменившиеся файлы пропускаются по размеру и точному LastWriteTimeUtc источника/назначения. Не пересчитываем хеш всех игровых данных на каждом запуске. При ручной замене файла с сохранением его размера и времени использовать `-ForceCopy`. Удалённые из источника файлы из назначения не удаляются; сохранения и настройки не затрагиваются.

Русский каталог CP1251 кэшируется в build/translations. Изменение исходного ru.po или msgfmt инвалидирует кэш. Вывод показывает copied, skipped, bytes и elapsed_ms. На настоящих данных повторная подготовка пропустила 196 файлов, скопировала 0 байт и заняла около 305 мс в проверенном запуске.

```powershell
./tools/prepare-game-data.ps1 -ForceCopy
./tools/test-menu-infrastructure.ps1
```

Последняя команда не запускает Azahar: создаёт маленькие искусственные данные в build, проверяет начальное/повторное/изменённое/принудительное копирование, вложенные карты, переименование музыки, сохранность saves/config, планы всех групп и отказ на неизвестной группе. Если есть исторический полный лог New, дополнительно проверяет совместимость маркеров с ним.

## Выполненная проверка

ARM Release (два потока), desktop-синтаксис game_mainmenu.cpp/ui_3ds_dialog.cpp, применение экспортированного патча к чистой базе, синтаксис PowerShell, автономные проверки и два прохода подготовки настоящих ресурсов прошли. Прогонов новых групп в эмуляторе не было; улучшение их фактической длительности и причина зависания ПК ещё не подтверждены. Эти изменения относятся к тестовой инфраструктуре, отдельного обновления на консоли не требуют.
